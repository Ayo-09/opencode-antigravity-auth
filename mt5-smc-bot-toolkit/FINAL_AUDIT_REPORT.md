## 2. ملخص المرجع المرفق (PDF — صفحتان)

**«المرجع الشامل لاستراتيجية الهجينة المدعومة بالذكاء الاصطناعي — AI-SMC/ICT»** يحدد:
1. **التوجه اليومي (Daily Bias)** على D1 — الإزاحة الشمعية (Desplazamiento).
2. **قوة الثلاثة (Power of 3 – PO3)** على H4/30M: تراكم (Accumulation) → تلاعب (Manipulation) → حركة التوزيع.
3. **تأكيد SMC** على H1: انتظار إغلاق الشمعة + **CHoCH/MSS** + **منطقة Bullish/Bearish FVG / Order Block**.
4. **محرك الدخول (Execution Engine)** على M1: **دخول قناص (Sniper Entry)** عند **تأكيد CISD**.
5. **وقف الخسارة:** أسفل **السيولة الحقيقية (Actual Liquidity)** داخل **FVG**.
6. **الهدف (Take Profit):** عند **السيولة التالية** مع **R:R 1:2 → 1:3 → 1:4 (أقصى)**.
7. **المخاطرة:** 1–2% لكل صفقة، حد يومي 1–2%، **فلتر Anti-Trap**، والتركيز على **افتتاح جلسة لندن**.
8. أنظمة AI مستخدمة في المراقبة: **AI Engine 1** (تصفية الإزاحة الشمعية) · **AI Engine 2** (تتبع PO3) · **AI Engine 3** (كشف الإغراء/السيولة الحقيقية).

> وقد تمت مطابقتها كلها في `SMC_ICT_Pro_V2.mq5`.

## 3. مطابقة البوت للملف المرجعي (نقطة بنقطة)

| مكوّن الملف | التنفيذ في MQL5 |
|---|---|
| `1D Daily Bias / Desplazamiento` | `GetDailyBias()` — إغلاق الشمعة اليومية + كسر قمة/قاع اليوم السابق |
| `PO3 H4/M30: Accumulation → Manipulation` | `DetectPO3Buy()/DetectPO3Sell()` — نطاق تراكم ضيق ثم فتيل كنس للقيعان/القمم مع إغلاق رفض |
| `SMC Confirm H1: CHoCH/MSS` | `DetectSMCConfirmBuy()/Sell()` — كسر آخر قمة/قاع بعد انخفاض/صعود |
| `Bullish/Bearish FVG (H1)` | `FindBullishFVG()/FindBearishFVG()` — فجوة بين شمعتين |
| `Sniper Entry M1 + CISD` | `DetectCISDBuy()/Sell()` — كسر بنية M1 داخل FVG |
| `SL أسفل السيولة الحقيقية داخل FVG` | `GetBuySLTP()/GetSellSLTP()` — `SL = min(كنس, قاع FVG) − نقطتين` |
| `TP عند السيولة التالية / RR 1:2-1:3-1:4` | `FindNextLiquidityUp/Down` + سقف `InpTargetRR` (≥1:2، ≤1:4) |
| `Risk 1–2%` | `InpRiskPerTradePercent=1.00` + سقف صلب `2.00` |
| `حد يومي 1–2%` | `InpDailyLossLimitPercent=2.00` |
| `Anti-Trap Filter` | إلزام كنس السيولة الحقيقية + تأكيد H1/M1 + FVG |
| `افتتاح جلسة لندن` | `InpFocusOnLondonOpening=true` + نافذة 07:00–11:00 |
| لوحة/سجل | Dashboard + Journal/CSV |

### الالتزامات العامة من البرومبت (كلها موجودة)
- `#property strict` · إدارة مخاطر كاملة · فلاتر سبريد/انحراف/جلسات/أخبار/نهاية أسبوع · `OnTradeTransaction` · Journal · لوحة · Net P&L · لا Martingale/Grid · لا تحريك SL بعيداً · لا `Retcode` بدون تسجيل.

## 4. مراجعة الملفين الآخرين (دون اعتماد)

### 4.1 Backtest_Guide (360 سطراً)
- بوت مختلف بنظام **Momentum/EMA + Pips** (`StopLossInPips`, `TargetProfitInPips`, `MomentumPeriod1`, `EMAPeriod`…). لذلك **لم يُستخدم** في بناء AI-SMC/ICT.
- ما أُخذ كمرجع عام فقط: `Every tick/real ticks`، تقسيم 70/30، اختبار أطر/رموز متعددة، حد تراجع، VPS.
- ⚠️ القيم «2-15%/شهر، Win 65-70%» أهداف وليست ضماناً.

### 4.2 ملف التعديلات الثانوي (313 سطراً)

- جرى تقييمها في الجدول أدناه (الأهمية/السبب/الأولوية/الخطورة). أي تنفيذ ينتظر موافقتك الصريحة.

## 5. خطة الاختبار (Baseline → Stress → Optimization → Forward → Demo)
1. **Baseline:** Ctrl+R، `SMC_ICT_Pro_V2.ex5`، رمز/وسيط حقيقي، `Backtesting mode: Every tick based on real ticks`، فترة 2–3 سنوات، لوت 0.01 أو مخاطرة 0.5–1%.
2. **Stress:** سبريد +20%، انزلاق أعلى، فترات أخبار، فترة خارج الضبط.
3. **Optimization محدود:** 2–4 معلمات (مثل `InpTargetRR`, `InpPO3AccumBars`, `InpSwingScanBars`) مع قيود MaxDD/عدد صفقات/PF.
4. **Forward/Out-of-Sample:** 70/30؛ انهيار Forward = Overfitting.
5. **Demo حي:** 4–8 أسابيع على نفس الوسيط؛ قارن عدد الصفقات، السبريد، الانزلاق، العمولة، MaxDD.
6. **الحي:** فقط بعد اجتياز 1–5 وبحجم صغير.

### شروط إيقاف فورية
- تجاوز الحد اليومي/الأسبوعي/التراجع/سلسلة الخسائر → منع جديد (و`Cooldown`).

## 6. أمر MT5 لاسم الملف في الصفقة
> MT5 لا يحفظ اسم الملف؛ يحفظ **Magic** و**Comment ≤ 31**.

```mql5
string eaName = MQLInfoString(MQL_PROGRAM_NAME);
int    dot    = StringFind(eaName, ".");
if(dot >= 0) eaName = StringSubstr(eaName, 0, dot);
if(StringLen(eaName) > 31) eaName = StringSubstr(eaName, 0, 31);
trade.SetComment(eaName);
```
- Magic: `702001` + `MagicToFile_Map.csv`.
- `TradeMonitor_Script.mq5` يسجل كل صفقة عبر `OnTradeTransaction`.
