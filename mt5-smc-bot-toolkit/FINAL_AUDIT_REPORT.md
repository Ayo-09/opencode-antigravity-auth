## 1. منهجية التدقيق المخطط لها
عند تسليم الملفات سيُنفَّذ التالي بالترتيب:

1. **جرد/محاذاة الأسطر**: استخراج الملفات إلى `mt5-smc-bot-toolkit/sources/` والحفاظ على البنية الأصلية.
2. **التدقيق الفني** (سطراً بسطر):
   - رموز MQL5 فقط (`MqlTradeRequest`, `CTrade`, `OnTick`, `OnTradeTransaction`, `OnInit`, `OnDeinit`).
   - `OnInit` تحقق إعدادات الرموز/المخاطر قبل أي صفقة.
   - `OrderSend`/`CTrade` استخدام `retcode` و`SetExpertMagicNumber`.
   - معالجة `GetLastError`, `MathAbs`, `CheckPointer`, `Digits`, `_Point`.
   - صحة معادلات: FVG، CHoCH، OTE 61.8–79%، مستوى السيولة، SL/TP، RR.
   - تجنب `while` بلا حد، تقسيم صفر، `ArrayResize` على مصفوفة غير مُهيأة.
   - الدوال غير المعرّفة أو المتروكة placeholder، والـ`input` غير المستخدمة.
3. **التدقيق المنطقي** (كلمة بكلمة):
   - هل الإشارة تُشكَّل بالترتيب المطلوب: Bias → Liquidity → Sweep → CHoCH → FVG → OTE → Entry → Manage → Close؟
   - هل SL يأتي خلف الكنس، وTP/السيولة أمام الهدف؟
   - هل يشترك مع سجل الصفقات، والـ Experts Journal؟
4. **التوافق مع المطلوب:** كشف تلقائي لنوع الرمز/العملة/الإطار/الجلسة، ودعم كريبتو/USDT، فوركس، أسهم، سلع.
5. **التقرير النهائي** يضيف: عدد الأسطر، عدد النقاط المضبوطة، جدول الأخطاء، توصيات التحسين، خطة النشر.

## 2. مبدأ العمل الأساسي المستهدف (SMC/ICT)
البوت يتبع نموذجاً هيكلياً قائماً على السيولة لا على مؤشرات تأخير:

1. **الانحياز العام (HTF Bias):** قراءة الشارت الأعلى لتحديد الاتجاه.
2. **خريطة السيولة:** تحديد قمم/قيعان متساوية (EQH/EQL)، قمم/قيعان سابقة (PDH/PDL)، ومناطق إنشاء أوامر.
3. **كنس السيولة (Stops Run / Sweep):** اختراق حاد للمستوى ثم رفض، ما يعلن احتباس الأوامر.
4. **انعكاس الهيكل (CHoCH):** كسر آخر قاع/قمة يؤكد الاتجاه الجديد.
5. **فجوة القيمة العادلة (FVG):** منطقة عدم توازن، وهدف التصحيح.
6. **المدخل المثالي (OTE 61.8–79%):** منطقة الدخول، والأفضل عند تقاطعها مع FVG.
7. **التنفيذ:** SL خلف الكنس، TP أمام الهدف، Comment وMagic دقيقان.
8. **الإدارة:** TP1 جزئي → بريك-إيفن → مطاردة TP2.
9. **الإغلاق:** تسجيل النتيجة خطوة بخطوة.

## 3. أمر مهم: لماذا لا يظهر اسم الملف في الصفقات؟
> **الحقيقة التقنية:** ميتاتريدر **لا يحفظ اسم ملف البوت في الصفقة اطلاقاً**. لا يوجد حقل
> "اسم الإكسبيرت" في السجل. الخادم يحفظ شيئين فقط لكل صفقة:
> 1. **الماجيك (Magic Number)** ← رقم فقط، ولا يخبرك بالاسم.
> 2. **التعليق (Comment)** ← نص قصير (حد أقصى ~31 حرفاً) يرسله البوت عند فتح الأمر.

لذلك "الاسم" الذي يظهر في الصفقات هو **نص التعليق** الذي كتبه البوت برمجياً، وليس اسم الملف تلقائياً.

### الحل 1: جعل البوت يكتب اسمه في التعليق تلقائياً (للصفقات المستقبلية)
```mql5
// في OnInit بعد SetExpertMagicNumber(...)
string eaName = MQLInfoString(MQL_PROGRAM_NAME);      // اسم الملف الحالي
int    dot    = StringFind(eaName, ".");
if(dot >= 0) eaName = StringSubstr(eaName, 0, dot);   // إزالة .ex5
if(StringLen(eaName) > 31) eaName = StringSubstr(eaName, 0, 31);
trade.SetComment(eaName);                              // يظهر اسم الملف في كل الصفقات
```
**مع `OrderSend`:** ضع اسم الملف قبل تعليق الاستراتيجية مع مراعاة حد 31 حرفاً:
```mql5
string eaName  = MQLInfoString(MQL_PROGRAM_NAME);
int    dot     = StringFind(eaName, ".");
if(dot >= 0) eaName = StringSubstr(eaName, 0, dot);
string fullComment = eaName + " | " + comment;
if(StringLen(fullComment) > 31) fullComment = StringSubstr(fullComment, 0, 31);
req.comment = fullComment;
```

> ⚠️ **مهم:** التعديل ينطبق فقط على الصفقات **المستقبلية** بعد إعادة الترجمة والتشغيل.
> لا توجد طريقة في MT5 لتعديل `comment` صفقة موجودة/سابقة.

### الحل 2: معرفة أي ملف فتح الصفقات (حتى القديمة)
- **خريطة الماجيك → الملف:** الماجيك هو المعرّف الوحيد الموثوق والثابت. سجّل كل ماجيك مع اسم ملفه في
  `MagicToFile_Map.csv`.
- **دفتر اليومية (Experts Journal):** عند تشغيل البوت يكتب MT5 سطراً في `MQL5\Logs\YYYYMMDD.log`.
- **الشارتات المفتوحة:** `list_open_charts` تُظهر أي EA مركّب على أي رمز.
- **بوستات `Print()`:** قد تظهر أسطراً باسم الأداة نفسها.

## 5. خطة النشر على حساب حقيقي
1. الترجمة في MetaEditor والتأكد من 0 أخطاء (تنسيق MQL5 / MetaTrader 5).
2. الاختبار في Strategy Tester على عدة رموز وأطر (H1/H4 على الأقل).
3. حساب تجريبي عائم (مليون دولار افتراضي) لمدة ≥ أسبوعين.
4. حساب تجريبي حقيقي 30+ يوم مع الحد الأدنى للرصيد.
5. إدارة المخاطر: ≤1% لكل صفقة، RR مستهدف ≥1:1.5.
6. مراقبة يومية عبر `Experts Journal` + `SMCTrades_Log.csv`.
7. زيادة تدريجية للرصيد بعد ثبات النتائج (لا قبل ذلك).

- التقاط وقت الجلسة للتقرير (روابط مؤشرات التداول، اختياري).
- منع البوت من العمل في "أوقات غير سائلة" يحددها المستخدم (اختياري).
