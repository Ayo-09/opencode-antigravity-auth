منصة مراجعة وبناء وتدقيق بوت التداول الآلي SMC/ICT على MetaTrader 5.

| الملف | الغرض |

| `index.html` | المنصة التفاعلية: المحاكاة + العرض + الإنفوجرافيك + التقرير + جدول المقارنة + صفحة التنزيل المباشر |

## مبدأ العمل
- البوت لا Martingale / Grid / تحريك SL بعيداً.
- اللوت يُحسب بالمخاطرة، والصفقة لا تُفتح بدون Stop Loss صالح.
- لا يعد بالربح: الاختبار التاريخي ليس ضماناً للأداء الحي.
