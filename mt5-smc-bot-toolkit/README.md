## المحتويات
| الملف | الغرض |
|---|---|
| `index.html` | المنصة التفاعلية: المحاكاة + العرض + الإنفوجرافيك + التقرير + جدول المقارنة + صفحة التنزيل المباشر |
| `files/` | الملفات القابلة للتنزيل المباشر (يُملأ بعد بناء البوت): `.mq5` · `.mqh` · `.csv` |
