# عرش الهاوية: شظايا النور — Throne of the Abyss: Shards of Light

**الفصل الأول: سهول البداية** — شريحة قابلة للّعب (vertical slice) مبنية من وثيقة تصميم اللعبة (GDD v0.1).

لعبة أكشن على Canvas 2D بلا أي تبعيات ولا خطوة بناء: HTML + CSS + JS خام، رسوم إجرائية (procedural) بالكامل،
وصوت مُركَّب عبر WebAudio. تعمل بـ 60fps على الحاسوب والهاتف.

## التشغيل

**أمر مباشر (يُنشئ الخادم ويفتح المتصفح تلقائيًا):**

```bash
./game/run.sh            # macOS / Linux
game\run.bat             # Windows (ثم http://localhost:8080)
```

أو يدويًا — افتح `game/index.html` مباشرة في المتصفح، أو:

```bash
cd game
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## الحلقة الأساسية

1. **موجات القتال (4)** — 6 أنواع وحوش من GDD: المنبوذ، ذئب الرماد، رامي الرماد، حارس الحقل (درع أمامي)،
   حشرة الصدع (أسراب)، وفارس العظم (يعود من الموت ما لم تُدمَّر نواته الزرقاء).
2. **الزعيم: غاروك، آكل السهول** — 4 مراحل كما في GDD:
   - غضب الوحش: ضربة أرضية موجية + اندفاع مستقيم.
   - قطيع الرماد: يستدعي ذئاب رماد (اقطعها لتشحن حرارة اللهب).
   - **انكسار القرن**: اصطدم غاروك بالأعمدة فينفخ قرناه برتقاليًا (مع دقة صوتية) — اركّز هجومك؛
     الضرب ×3 والنواة تتكشف. **مكافأة الطمع**: الضرب بعد إغلاق النافذة يطلق موجة ارتداد.
   - هياج الهاوية: الساحة تضيق، برَك نار، وزعيم أسرع.
3. **مكافآت**: ذهب من القتل، مكافأة إكمال موجة، شظايا روح من الزعيم، وتقييم 1–3 نجوم
   (زمن قتال الزعيم + الضرر الملتقى) — مع حفظ نصف الذهب عند السقوط، وفق مبدأ «الفشل لا يمحو المحاولة».

## أنظمة من GDD

- **حرارة اللهب (0–100)**: تبنى بالضربات، تنخفض عند تلقي الضربات؛ عند الامتلاء يشتعل **اللهب المتوج**
  (6 ثوانٍ: ضرر ×1.6 ومدى أوسع وهالة لهب).
- **الاقتصاد**: الذهب (شائع) للشراء اليومي، شظايا الروح (متوسطة) من الزعيم، وكل شيء يُكسب باللعب.
  لا إعلانات إجبارية — الخيارات الإعلانية من GDD موطّنة لاحقًا في اقتصاد «المسار المزدوج».
- **التقييم النجمي**: نجمة للإكمال، وثلث النجوم بزمن ممتاز وضرر منخفض.
- **سجل النتائج المحلي** (localStorage): أفضل 5 نتائج مع النجوم والموجة والتاريخ.
- **تقدم محفوظ**: ذهب/شظايا المخزن وفكّ سلاح «ناب السهل» بعد هزيمة غاروك.

## مؤشرات الأداء

- تحديث بفترات ثابتة (fixed timestep 60Hz) + rAF للعرض.
- بركة جسيمات محدودة (~350) و sprites متوهجة مُسبقة التصيير (لا shadowBlur ديناميكي).
- تجميد إطار (hit-stop) واهتزاز شاشة في لحظات القتل والضربات الحاسمة.

## الملفات

- `index.html` — الهيكل والواجهات (RTL عربي).
- `game.css` — الثيم البصري (ذهبي/بنفسجي فاسد).
- `game.js` — كل منطق اللعبة والرسوم والصوت (~1500 سطر).
- `smoke.cjs` — اختبار دخان عبر Node يحاكي أطر اللعبة ويختبر الحافة (شغّله: `node smoke.cjs`).
