1. مقدمة في الباك تيست
═══════════════════════════════════════════════════════════════════════════════

ما هو الباك تيست؟
──────────────────
الباك تيست هو اختبار استراتيجية التداول على بيانات تاريخية لمعرفة
كيف كانت ستؤدي في الماضي. هذا يساعد في:
• تقييم فعالية الاستراتيجية
• تحسين المعلمات
• اكتشاف المشاكل قبل التداول الحي
• بناء الثقة في النظام

لماذا نستخدم البوت
─────────────────────────────────────────────────────
• نسخة مُحسّنة خصيصاً للـ Strategy Tester
• معلمات محددة للتحسين
• تعليقات توضيحية لكل معلم
• إعدادات افتراضية مناسبة للبداية

2. إعداد Strategy Tester
═══════════════════════════════════════════════════════════════════════════════

الخطوة 1: فتح Strategy Tester
──────────────────────────────
MetaTrader 5 → View → Strategy Tester
أو اضغط: Ctrl + R

الخطوة 2: اختيار الإعدادات الأساسية
─────────────────────────────────────
┌─────────────────────────────────────────────────────────────────────────────┐
│  الحقل              │  القيمة المقترحة    │  الشرح                        │
├─────────────────────────────────────────────────────────────────────────────┤
│  Expert             │  ملف البوت  │  اختر النسخة  │
│  Symbol             │  EURUSD             │  زوج العملات المستهدف        │
│  Timeframe          │  H1                 │  الإطار الزمني               │
│  Date (From)        │  2025-08-01         │  بداية فترة الاختبار         │
│  Date (To)          │  2026-08-01         │  نهاية فترة الاختبار         │
│  Model              │  Every tick         │  أعلى دقة (بطئ لكن دقيق)    │
│  Optimization       │  Slow complete      │  خوارزمية التحسين الكاملة   │
│  Initial Deposit    │  10000              │  الرصيد الافتراضي ($)        │
│  Leverage           │  1:100              │  الرافعة المالية             │
└─────────────────────────────────────────────────────────────────────────────┘

⚠️  مهم: استخدم "Every tick" للدقة العالية
    استخدم "OHLC on M1" للسرعة (أقل دقة)

الخطوة 3: إعدادات التحسين
──────────────────────────
1. اختر "Optimization" → "Slow complete algorithm"
2. اضغط على زر "Expert properties" (الأزرق)
3. انتقل إلى تبويب "Testing"
4. اضبط:
   • Initial Deposit: 10000
   • Currency: USD
   • Leverage: 1:100
   • Execution: Normal

الخطوة 4: اختيار معلمات التحسين
─────────────────────────────────
انتقل إلى تبويب "Inputs"

المعلمات الموصى بتحسينها (ضع علامة ✓):
┌─────────────────────────────────────────────────────────────────────────────┐
│  المعلم                    │  البداية │  النهاية │  الخطوة │  الأولوية   │
├─────────────────────────────────────────────────────────────────────────────┤
│  StopLossInPips            │  5       │  30      │  5      │  ⭐⭐⭐       │
│  TargetProfitInPips        │  50      │  200     │  25     │  ⭐⭐⭐       │
│  RiskPercentagePerTrade    │  0.5     │  3.0     │  0.5    │  ⭐⭐⭐       │
│  MomentumPeriod1           │  10      │  30      │  2      │  ⭐⭐        │
│  StrongMomentumThreshold   │  30      │  60      │  5      │  ⭐⭐        │
│  EMAPeriod                 │  50      │  300     │  25     │  ⭐⭐        │
│  TrailingStopInPips        │  50      │  200     │  25     │  ⭐          │
│  TrailingStartInPips       │  20      │  100     │  10     │  ⭐          │
│  FirstPendingDistanceInPips│  20      │  80      │  5      │  ⭐          │
└─────────────────────────────────────────────────────────────────────────────┘

⚠️  لا تحسّن أكثر من 3-4 معلمات في نفس الوقت!
    هذا يمنع "Overfitting" (التحسين المفرط)

الخطوة 5: معايير التحسين
─────────────────────────
انتقل إلى تبويب "Optimization criteria"

الإعدادات الموصى بها:
┌─────────────────────────────────────────────────────────────────────────────┐
│  المعيار الرئيسي:    Balance Max (الرصيد الأقصى)                         │
│  المعيار الثانوي:    Profit Factor Max                                    │
│  القيود:                                                                │
│    • Max Drawdown < 20% (الخسارة القصوى أقل من 20%)                     │
│    • Min Trades > 50(عدد صفقات كافٍ)                                    │
│    • Max Consecutive Losses < 10                                          │
└─────────────────────────────────────────────────────────────────────────────┘

3. خطوات التحسين (Optimization)
═══════════════════════════════════════════════════════════════════════════════

المرحلة 1: التحسين الأولي (الأولوية العالية)
──────────────────────────────────────────────
1. فعّل فقط معلمات الأولوية ⭐⭐⭐
2. اضبط النطاقات الواسعة
3. شغّل التحسين
4. انتظر النتائج (قد يستغرق ساعات)

المرحلة 2: التحسين المتوسط (الأولوية المتوسطة)
───────────────────────────────────────────────
1. خذ أفضل نتيجة من المرحلة 1
2. فعّل معلمات الأولوية ⭐⭐
3. اضبط نطاقات أضيق حول القيم الجيدة
4. شغّل التحسين

المرحلة 3: التحسين الدقيق (الأولوية المنخفضة)
───────────────────────────────────────────────
1. خذ أفضل نتيجة من المرحلة 2
2. فعّل معلمات الأولوية ⭐
3. اضبط نطاقات ضيقة جداً
4. شغّل التحسين النهائي

المرحلة 4: التحقق
──────────────────
1. خذ أفضل نتيجة نهائية
2. شغّل باك تيست عادي (بدون تحسين)
3. راجع الرسم البياني للصفقات
4. تأكد من منطقية النتائج

═══════════════════════════════════════════════════════════════════════════════
4. قراءة وتحليل النتائج
═══════════════════════════════════════════════════════════════════════════════

أهم المقاييس:
──────────────

┌─────────────────────────────────────────────────────────────────────────────┐
│  المقياس          │  الجيد      │  الممتاز   │  التحذير                  │
├─────────────────────────────────────────────────────────────────────────────┤
│  Total Net Profit │  > $500     │  > $2000   │  < $0 (خسارة)            │
│  Profit Factor    │  > 1.3      │  > 1.8     │  < 1.0 (خسارة)           │
│  Recovery Factor  │  > 2.0      │  > 4.0     │  < 1.0                   │
│  Max Drawdown     │  < 15%      │  < 10%     │  > 25% (خطير)            │
│  Sharpe Ratio     │  > 1.0      │  > 1.5     │  < 0.5                   │
│  Win Rate         │  > 50%      │  > 60%     │  < 40%                   │
│  Total Trades     │  > 50       │  > 100     │  < 20 (عينة صغيرة)      │
│  Avg Trade        │  > $5       │  > $20     │  < $0                    │
│  Max Consecutive  │  < 5        │  < 3       │  > 10 (خطير)             │
│  Losses           │             │            │                          │
└─────────────────────────────────────────────────────────────────────────────┘

كيفية قراءة الرسم البياني:
───────────────────────────
1. رسم Equity Curve (منحنى الربح):
   • يجب أن يكون اتجاهه صاعداً بشكل عام
   • تجنب المنحنيات المتذبذبة بشكل مفرط
   • تجنب الانخفاضات الحادة

2. رسم Balance vs Equity:
   • يجب أن يكونا متقاربين
   • الفجوة الكبيرة = صفقات مفتوحة خاسرة

3. رسم توزيع الصفقات:
   • توزيع متوازن بين الربح والخسارة
   • تجنب التركيز في فترة واحدة

5. التحقق من الأمام (Forward Testing)
═══════════════════════════════════════════════════════════════════════════════

ما هو Forward Testing؟
───────────────────────
اختبار الاستراتيجية على بيانات لم تُستخدم في التحسين
للتأكد من أن النتائج ليست "Overfitted"

الخطوة 1: تقسيم البيانات
──────────────────────────
┌─────────────────────────────────────────────────────────────────────────────┐
│  فترة التحسين (In-Sample):    70% من البيانات (مثلاً 8 أشهر)            │
│  فترة التحقق (Out-of-Sample): 30% من البيانات (مثلاً 4 أشهر)            │
└─────────────────────────────────────────────────────────────────────────────┘

الخطوة 2: التحسين على In-Sample
─────────────────────────────────
1. اضبط التاريخ من: 2025-01-01 إلى: 2025-08-31
2. شغّل التحسين
3. احفظ أفضل الإعدادات

الخطوة 3: الاختبار على Out-of-Sample
──────────────────────────────────────
1. اضبط التاريخ من: 2025-09-01 إلى: 2025-12-31
2. استخدم الإعدادات المحسّنة (بدون تحسين جديد)
3. شغّل الباك تيست
4. قارن النتائج

الخطوة 4: تقييم النتائج
────────────────────────
إذا كانت نتائج Out-of-Sample مشابهة لـ In-Sample:
✅ الاستراتيجية قوية ويمكن الاعتماد عليها

إذا كانت نتائج Out-of-Sample أسوأ بكثير:
❌ الاستراتيجية "Overfitted" - أعد التحسين بنطاقات أضيق

6. نصائح احترافية
═══════════════════════════════════════════════════════════════════════════════

نصيحة 1: تجنب Overfitting
──────────────────────────
• لا تحسّن أكثر من 3-4 معلمات
• استخدم نطاقات واسعة أولاً
• تحقق دائماً بـ Forward Testing
• إذا كان الربح مرتفع جداً (>100% شهرياً) = تحذير!

نصيحة 2: اختبار متعدد الأزواج
───────────────────────────────
• اختبر على 3-5 أزواج مختلفة
• EURUSD, GBPUSD, USDJPY, XAUUSD , btcusd , ethrusd او اي رمز اخر
• إذا نجحت على معظمها = استراتيجية قوية
• إذا نجحت على زوج واحد فقط = ضعيفة

نصيحة 3: اختبار متعدد الأطر
────────────────────────────
• اختبر على H1, H4, D1
• H1 = أكثر صفقات، أكثر ضوضاء
• H4 = توازن جيد
• D1 = أقل صفقات، أكثر موثوقية

نصيحة 4: مراعاة السبريد والعمولة
───────────────────────────────────
• اضبط السبريد الحقيقي لوسيطك
• أضف عمولة التداول إن وجدت
• اختبر مع سبريد أعلى بـ 20% (Stress Test)

نصيحة 5: اختبار الضغط (Stress Test)
─────────────────────────────────────
• اختبر خلال أزمات السوق (مارس 2020, فبراير 2022 / نوفمبر 2024 , ماي 2025 )
• اختبر مع تقلب مرتفع
• اختبر مع سبريد واسع
• الاستراتيجية القوية تتحمل الضغط

نصيحة 6: استخدام VPS للباك تيست في حالة وجوده
──────────────────────────────────
• VPS أسرع من الكمبيوتر الشخصي
• يمكن تشغيل باك تيستات متعددة
• لا يتأثر بإغلاق الكمبيوتر
• موصى به للتحسينات الكبيرة

🔧 استكشاف أخطاء الباك تيست
═══════════════════════════════════════════════════════════════════════════════

المشكلة: "No trades were made"
├── الحل: تحقق من شروط الدخول (Momentum thresholds)
├── الحل: تأكد من توفر البيانات التاريخية
└── الحل: جرب فترة زمنية أطول

المشكلة: "Too many trades"
├── الحل: ارفع عتبة الزخم (StrongMomentumThreshold)
├── الحل: فعل "New Bar Only" control
└── الحل: ارفع حد الصفقات القصوى

المشكلة: "High drawdown"
├── الحل: زيادة StopLoss
├── الحل: تقليل RiskPercentage
├── الحل: تفعيل Trailing Stop
└── الحل: تقليل Max Positions

المشكلة: "Low profit factor"
├── الحل: زيادة TargetProfit
├── الحل: تقليل StopLoss
├── الحل: تحسين عتبات الزخم
└── الحل: إضافة فلاتر إضافية

المشكلة: "Optimization too slow"
├── الحل: استخدم "OHLC on M1" بدلاً من "Every tick"
├── الحل: قلل عدد المعلمات المحسّنة
├── الحل: استخدم VPS أقوى
└── الحل: اضيق النطاقات
